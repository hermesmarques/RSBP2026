Inferência estatística e tabelas automatizadas

Tradicionalmente, os resultados de testes estatísticos no R são exibidos em blocos de texto difíceis de manipular no console. No R moderno, utilizamos o pacote broom para transformar saídas de modelos estatísticos complexos (como objetos lm ou t.test) em tibbles limpas e organizadas.

Para a geração automática de matrizes de correlação e tabelas de regressão no formato oficial da APA, utilizaremos o pacote apaTables (Stanley & Spence, 2018).

library(tidyverse)
library(broom)
# Caso não tenha o pacote instalado, use: install.packages("apaTables")
library(apaTables) 
library(papaja)

Teste \(t\) de Student para amostras independentes

Vamos testar a hipótese de que participantes de um grupo experimental de meditação apresentam menores níveis de cortisol (estresse biológico) em comparação ao grupo de controle.

# Simulando os dados de 30 participantes
set.seed(123)
dados_cortisol <- tibble(
  grupo = rep(c("Controle", "Meditação"), each = 15),
  cortisol = c(rnorm(15, 18, 4), rnorm(15, 14, 3.5))
)

# Executando o teste t e transformando o resultado em uma tibble com broom
resultado_t <- t.test(cortisol ~ grupo, data = dados_cortisol, var.equal = TRUE) |> 
  tidy()

Análise de Variância (ANOVA) simples

Quando comparamos três ou mais grupos, recorremos à ANOVA. Vamos avaliar o impacto de três abordagens terapêuticas nos sintomas de depressão.

dados_terapia <- tibble(
  terapia = rep(c("TCC", "Psicanálise", "Lista de Espera"), each = 20),
  depressao = c(rnorm(20, 12, 3), rnorm(20, 15, 4), rnorm(20, 22, 5))
)

# Ajustando o modelo linear e extraindo a tabela ANOVA organizada
modelo_anova <- lm(depressao ~ terapia, data = dados_terapia) |> 
  anova() |> 
  tidy()

Tabelas automatizadas da APA com apaTables

Copiar coeficientes de regressão ou correlações manualmente para o Word ou LaTeX é uma das maiores fontes de erro em publicações científicas. O pacote apaTables resolve isso gerando arquivos prontos que seguem os padrões de formatação da APA 7.

Matriz de Correlação APA

A função apa.cor.table() cria uma tabela clássica da APA com médias, desvios-padrão e correlações indicadas por asteriscos para significância estatística.

# Simulando variáveis psicológicas contínuas
dados_psicometria <- tibble(
  Autoestima = rnorm(50, 25, 5),
  Ansiedade = 40 - (Autoestima * 0.6) + rnorm(50, 0, 3),
  Satisfacao_Vida = (Autoestima * 0.8) + rnorm(50, 0, 4)
)

# Gerando a tabela APA (ela salva um arquivo .doc no seu diretório de trabalho)
apa.cor.table(dados_psicometria, 
              filename = "Tabela1_Correlacoes_APA.doc", 
              show.conf.interval = FALSE)

Tabela de regressão linear múltipla

Da mesma forma, podemos gerar tabelas completas de modelos de regressão, incluindo coeficientes não-padronizados (B), padronizados (\(\beta\)), intervalos de confiança e o \(R^2\) do modelo.

# Ajustando um modelo de regressão múltipla
modelo_regressao <- lm(Satisfacao_Vida ~ Autoestima + Ansiedade, data = dados_psicometria)

# Gerando a tabela de regressão padronizada da APA
apa.reg.table(modelo_regressao, 
              filename = "Tabela2_Regressao_APA.doc")

Nota: O pacote apaTables exportará automaticamente os arquivos organizados com as linhas e fontes corretas diretamente no seu computador para que você possa incorporá-los ao seu relatório final.

Renderização nativa e dinâmica com papaja

Enquanto o apaTables cria arquivos externos, o pacote papaja (Aust & Barth, 2026) permite renderizar tabelas padronizadas da APA diretamente no corpo do documento durante o processo de renderização do R Quarto. A grande vantagem é que, se os dados mudarem, a tabela se atualiza automaticamente sem gerar novos arquivos no computador. Para renderizar tabelas perfeitamente em PDF ou Word, a função principal utilizada é a apa_table(). É obrigatório configurar o bloco de código com o argumento results = "asis".

Formatação de Tabelas de Modelos Estatísticos

O papaja integra-se com funções de impressão integradas (como apa_print()) para extrair e organizar automaticamente estatísticas de testes como ANOVAs e Regressões diretamente para tabelas formatadas.

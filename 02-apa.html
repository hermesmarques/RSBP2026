Organização do manuscrito estilo APA em Quarto

Configuração do ambiente e fluxo de trabalho

A reprodutibilidade na pesquisa psicológica exige que o texto acadêmico, os dados brutos e os códigos estatísticos coexistam em um único ecossistema seguro. Este módulo fornece um guia passo a passo para configurar o Quarto utilizando a extensão apaquarto (Schneider, 2024), garantindo que seu manuscrito seja exportado nativamente nos padrões da American Psychological Association (2020).

Instalação de requisitos do sistema

Antes de iniciar a escrita, é necessário preparar o ambiente local instalando a ferramenta de renderização de PDFs (\(\LaTeX\)) e baixar o template da APA no diretório do seu projeto.

# 1. Instalar o TinyTeX (essencial para compilar PDFs acadêmicos de forma leve)
install.packages("tinytex")
tinytex::install_tinytex()

# 2. Adicionar a extensão oficial da APA 7ª edição ao seu projeto atual
install.packages("quarto")
quarto::quarto_add_extension("wjschne/apaquarto")

Alternativamente, é possível instalar pelo terminal usando o seguinte comando.

quarto use template wjschne/apaquarto

Pacotes em R Essenciais para Psicologia

Com a estrutura do documento instalada, precisamos dos pacotes que automatizarão a manipulação psicométrica e a formatação das tabelas estatísticas. Abra o seu console do R e execute:

# Instalação dos pacotes do CRAN
install.packages(c("tidyverse", "flextable", "ftExtra", "remotes"))

# Instalação do pacote utilitário para tabelas da APA 7 via GitHub
remotes::install_github("wjschne/apa7")

O pacote tidyverse será utilizado para a limpeza de dados e cálculo de escores de subescalas, enquanto o flextable e o apa7 ajudaram a construir tabelas com as linhas horizontais exigidas pela APA (mais a frente veremos alternativas usando o apaTables e o papaja.

Estrutura de um Documento Acadêmico (.qmd)

Todo documento Quarto formatado para a APA inicia-se com um cabeçalho YAML delimitado por três traços (---). É nele que metadados complexos (como afiliações múltiplas e autores correspondentes) são declarados.

Abaixo está o esqueleto padrão para o seu arquivo manuscrito.qmd:

---
title: "Efeito da fadiga cognitiva na tomada de decisão"
shorttitle: "Fadiga cognitiva e decisão"
author:
  - name: Aluno de pós-graduação
    corresponding: true
    orcid: 0000-0000-0000-0000
    email: pesquisador@universidade.br
    affiliations:
      - name: Universidade Pública Gratuita e de Qualidade
        department: Núcleo de Pesquisa em Psicologia
abstract: |
  O resumo deve conter um parágrafo único, sem recuo, sintetizando os objetivos, 
  método (incluindo características dos participantes), resultados principais e 
  conclusões do estudo. Geralmente varia entre 150 e 250 palavras.
keywords: [fadiga cognitiva, tomada de decisão, psicologia experimental]
lang: pt-BR
format:
  apaquarto-pdf:
    keep-tex: false
  apaquarto-docx: default
bibliography: referencias.bib
---

## Introdução

O texto da sua introdução começa diretamente aqui. Na norma APA, o título da introdução não deve receber o cabeçalho "Introdução", pois presume-se que a seção inicial cumpre esse papel. Citações podem ser feitas nativamente usando colchetes e a chave do BibTeX [@harris2020].

## Método

Esta seção detalha rigorosamente como a pesquisa foi conduzida, subdividida em subcabeçalhos táteis.

### Participantes

Descreva a amostra, critérios de inclusão/exclusão e dados demográficos fundamentais.

### Materiais e Procedimentos

Apresente os inventários psicométricos, tarefas experimentais e o passo a passo ético coletado.

## Resultados

Os resultados estatísticos devem ser apresentados de forma clara e objetiva. Tabelas dinâmicas podem ser geradas diretamente através de blocos de código (*code chunks*).

```{r}
#| echo: false
#| message: false

library(flextable)
library(apa7)

# Dados fictícios para demonstração
dados_exemplo <- data.frame(
  Condicao = c("Controle", "Experimental"),
  Media = c(7.42, 5.18),
  Desvio_Padrao = c(1.12, 1.45)
)
```

## Renderizando a tabela sob as regras da APA

```{r}
#| label: tbl-descritiva
#| tbl-cap: "Estatisticas Descritivas dos Grupos Amostrais"
apa_flextable(dados_exemplo)
```

Como demonstrado na @tbl-descritiva, observou-se uma variação latente entre as condições avaliadas.

quarto render manuscrito.qmd --to apaquarto-pdf
